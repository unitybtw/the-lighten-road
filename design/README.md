# Game design workspace

**Lead:** Furkan — @aeshmacodex

The [working GDD](../docs/GDD.md) remains the central design reference. Use this folder for supporting documents rather than creating a second GDD.

- [levels/](levels/): room layouts, puzzle flows, hazards, and completion paths.
- [balancing/](balancing/): proposed fuel values, costs, recovery amounts, and playtest revisions.

Use a branch such as `design/furkan/office-01`. Label proposed values as proposals until the team agrees. Explain mechanical changes in a pull request and update the GDD when accepted.
