# Art source workspace

Keep editable art sources in the artist's folder. Put exports beside their source in an `exports/` directory, retaining matching base names. Only reviewed game-ready exports should be imported into `Game/Assets/_Project/Art/` when the Unity project exists.

- [Can](can/): @benesas
- [Maksim](maksim/): @Ichnolith
- [Asset register](ASSET_REGISTER.md): source, author, license, and intended use.

Before sharing a sprite or tileset, record pixel dimensions, pixels per unit, pivot, palette, animation frame order, and intended scene. Agree these values with the developers; no values have been fixed yet. Keep one editor per binary source file. Coordinate before adding large files; Git LFS is not configured.
