# Archive menu typeface

Cormorant SC SemiBold by Christian Thalmann / Catharsis Fonts.

- Source: [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl/cormorantsc).
- Original font: `CormorantSC-SemiBold.ttf` (unmodified).
- License: SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
- The generated TextMeshPro SDF asset is `Assets/_Project/Resources/UI/ArchiveSerif.asset`.

The small-cap serif is used for menu titles and choices. Supporting descriptions and device callouts retain the existing sans-serif font for readability. The controller schematic is drawn by project code; Hollow Knight screenshots are reference material only and are not shipped assets.
